# IPA audio attribution

The `.ogg` files in this directory are local copies of IPA recordings from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Audio_files_of_linguistics).
They were retrieved on 2026-10-16 and are used without altering the recordings.

- Vowel files: Wikimedia Commons IPA vowel recordings; the file metadata lists
  Denelson83 as the assumed uploader/rights holder. License: CC BY-SA 3.0.
- Most consonant files: recordings credited on the corresponding Wikimedia
  Commons file pages, including Peter Isotalo. License: CC BY-SA 3.0.
- `j.ogg` (`Voiced palato-alveolar affricate.ogg`): original uploader Octane;
  public domain.

Local filename to Commons source-title mapping:

- Vowels: `i`=Close front unrounded vowel; `ih`=Near-close near-front
  unrounded vowel; `e`=Open-mid front unrounded vowel; `ae`=Near-open front
  unrounded vowel; `aa`=Open back unrounded vowel; `o`=Open back rounded
  vowel; `aw`=Open-mid back rounded vowel; `uh-short`=Near-close near-back
  rounded vowel; `u`=Close back rounded vowel; `uh`=Open-mid back unrounded
  vowel; `er`=Open-mid central unrounded vowel; `schwa`=Mid-central vowel.
- Consonants use their IPA sound-name titles. The non-obvious mappings are
  `theta`=Voiceless dental fricative, `eth`=Voiced dental fricative,
  `sh`=Voiceless postalveolar fricative, `zh`=Voiced postalveolar fricative,
  `ch`=Voiceless postalveolar affricate, `j`=Voiced postalveolar affricate,
  `ng`=Velar nasal, `r`=Postalveolar approximant, `y`=Palatal approximant,
  and `w`=Voiced labio-velar approximant.

The original source page can be opened as:

`https://commons.wikimedia.org/wiki/File:<source-title>.ogg`

The recordings remain available under the license shown on each source page.
